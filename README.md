# Cyber-Security-Task-4-Firewall-Configuration
CoTask 4: Setup and Use a Firewall on Windows

Objective

The objective of this task was to understand firewall functionality, configure firewall rules, block traffic on a specific port, test the rule, and restore the original configuration.

Tools Used

- Windows 11 Pro
- Windows Defender Firewall with Advanced Security
- Windows PowerShell

Task Performed

1. Opened Windows Defender Firewall with Advanced Security.
2. Reviewed existing inbound firewall rules.
3. Created a new inbound rule to block TCP Port 23 (Telnet).
4. Verified that the rule was successfully applied.
5. Tested the firewall configuration using PowerShell.
6. Removed the temporary rule after testing.
7. Documented the entire process and findings.

Key Concepts Learned

- Firewall Configuration
- Inbound and Outbound Rules
- Network Traffic Filtering
- TCP Ports
- Telnet (Port 23)
- Windows Firewall Management
- Basic Network Security

Outcome

Successfully configured and tested firewall rules on Windows. Gained practical experience in traffic filtering, firewall management, and network security fundamentals.
